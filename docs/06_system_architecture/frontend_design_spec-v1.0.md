## 三、每个页面的结构层次

### P1: 工作台首页 (Dashboard)

> **来源**: `flow_state_spec.md` §3.1 阶段 1 — Dashboard 入口（节点 1-2）

**页面目的**: 用户登录后的着陆页，提供全局视图和操作入口。

```
P1: Dashboard
├── 顶部导航栏 (TopNav)
│   ├── Logo / 系统名称
│   ├── 用户头像 + 下拉菜单（个人设置 / 退出）
│   └── [主操作按钮] "新建审阅" (Primary CTA)
│
├── 统计卡片行 (StatCards)
│   ├── 待处理审阅数
│   ├── 本周完成审阅数
│   ├── 平均审阅耗时
│   └── AI 发现风险总数
│
├── 快捷操作区 (QuickActions)
│   ├── "最近审阅"卡片列表（点击可继续审阅 or 查看报告）
│   └── "上传新文档"拖拽区（快捷入口）
│
└── 审阅任务列表 (TaskList)
    ├── 筛选栏（状态筛选 + 日期排序）
    ├── 任务行：文档标题 | 文档类型(NDA) | 状态 | 提交时间 | 风险摘要
    └── 分页器
```

**数据来源**: 后端提供 Dashboard 统计聚合数据 + 任务列表分页数据。

---

### P2: 新建审阅页（上传与配置）

> **来源**: `flow_state_spec.md` §3.1 + `upload_and_parsing_flow.md` 节点 3-10

**页面目的**: 用户上传文档、完成文件校验、配置解析选项。

```
P2: 新建审阅页
├── 步骤指示器 (Stepper): [1.上传文档] → [2.文件校验] → [3.解析配置] → [4.启动解析]
│
├── Step 1: 上传文档区 (UploadZone)
│   ├── 拖拽上传区域（支持 PDF / DOCX 格式提示）
│   ├── "选择文件"按钮
│   ├── 粘贴板上传提示文本
│   └── 上传中进度条（百分比 + 速度 + 取消按钮）
│
├── Step 2: 文件校验区 (ValidationPanel)
│   ├── 格式校验: ✅ 通过 / ❌ 失败 + 错误原因 + 支持的格式说明
│   ├── 文件大小/页数校验: 通过 / 超限提示
│   ├── 加密检测: ❌ 提示"文件已加密，请解除保护后重试"
│   ├── 损坏检测: ❌ 提示"文件可能已损坏，请重新导出"
│   └── OCR 检测: 扫描版 PDF → OCR 模式选择（"立即处理" / "后台处理并通知"）
│
├── Step 3: 解析配置区 (ConfigForm)
│   ├── 文档类型选择: 下拉框（MVP 默认且仅可选 "NDA 协议"）
│   ├── 文档标题输入: 文本框（默认取文件名）
│   ├── 标签输入: 标签选择器（可选）
│   └── Playbook 选择: 下拉框（MVP 默认 "NDA Standard Playbook"）
│
└── Step 4: 启动解析 (LaunchBar)
    ├── 配置摘要回显
    ├── "开始解析"按钮
    └── 自动触发模式开关（默认手动触发）
```

**数据来源**: 后端提供格式校验结果、OCR 检测结果。

### P3: 解析进度页

> **来源**: `flow_state_spec.md` §3.1 — 解析进度透明展示（节点 11-14）

**页面目的**: 展示文档解析的实时进度。

```
P3: 解析进度页
├── 页面头部
│   ├── 文档标题 + 文档类型(NDA)
│   └── 全局状态标签: "解析中" / "解析完成" / "解析失败"
│
├── 解析进度总览 (OverallProgress)
│   ├── 环形进度图（整体百分比 + 已完成/总步骤）
│   └── 预估剩余时间
│
├── 分 Agent 进度卡片 (AgentProgressCards) ← 差异化：按 Agent 维度展示
│   ├── 条款提取 Agent: [████████░░] 80%  已提取 8/10 类条款
│   ├── 风控 Agent:     [██████░░░░] 60%  已扫描 12/20 个条款
│   ├── 合规 Agent:     [██████████] 100% 已完成
│   └── 报告 Agent:     等待上游完成...
│
├── 实时操作日志流 (OperationLogStream) ← 差异化：非黑盒
│   ├── [10:23:15] 条款提取 Agent: 识别"保密义务"条款
│   ├── [10:23:18] 条款提取 Agent: 识别"保密期限"条款
│   └── [10:23:22] 风控 Agent: 发现中风险项 — "保密期限超过行业标准"
│
├── 解析失败面板 (FailurePanel — 条件渲染)
│   ├── 失败原因详情
│   ├── "重试"按钮（利用 Checkpointer 断点续传）
│   └── "重新上传"按钮
│
└── 底部操作栏
    ├── "取消解析"按钮
    └── "解析完成，进入 AI 审核" → 自动跳转 P4
```

**数据来源**: 后端通过 SSE/WebSocket 推送解析进度事件。

### P4: AI 审核进度页

> **来源**: `flow_state_spec.md` §3.2 — 4 Agent 并行进度可视化 + Checkpointer 断点恢复

**页面目的**: 展示 AI 多 Agent 审核的并行执行状态。

```
P4: AI 审核进度页
├── 页面头部
│   ├── 审阅任务标题
│   └── 全局状态标签: "AI 审核中" / "审核完成" / "部分成功"
│
├── Agent 编排视图 (AgentOrchestrationView)
│   ├── Supervisor 状态: "已编排 4 个 Agent，正在并行执行"
│   │
│   ├── Agent 并行执行卡片组
│   │   ├── ┌─────────────────┐  ┌─────────────────┐
│   │   │   │ 风控 Agent       │  │ 合规 Agent       │  ← 并行卡片（有连线示意）
│   │   │   │ ✅ 12/20 条款    │  │ ⏳ 8/10 合规项   │
│   │   │   │ 🔴高:3 🟡中:5  │  │ 当前: GDPR 检查  │
│   │   │   └─────────────────┘  └─────────────────┘
│   │   │
│   │   │   ┌─────────────────────────────────────┐
│   │   │   │ 报告 Agent                           │  ← 串行依赖（等待上游）
│   │   │   │ ⏸ 等待风控 + 合规 Agent 完成         │
│   │   │   └─────────────────────────────────────┘
│   │
│   ├── 审核失败面板 (ReviewFailurePanel — 条件渲染)
│   │   ├── 失败类别: AI 服务不可用 / 解析残留错误 / 超时
│   │   ├── 对应操作: "重试" / "人工接管" / "联系支持"
│   │   └── 超时提示: "审核超时，但已完成条款的风险数据保留可用"
│   │
│   ├── 部分成功面板 (PartialSuccessPanel — 条件渲染)
│   │   ├── 🟢 完成区: 已成功审阅的条款（风险数据完整可查看）
│   │   ├── 🟠 待审区: 未完成审阅的条款（原文可见，支持手动审阅/单个重试）
│   │   └── ⚠️ 警告: "风险统计仅覆盖已完成条款 (12/20)"
│   │
│   └── 暂停恢复区 (PauseResumeBar — 条件渲染)
│       ├── "暂停审核"按钮
│       ├── 暂停确认对话框
│       └── 恢复提示（断点恢复 UX）："检测到未完成的审核任务，是否从中断处继续？"
│
├── 审核完成摘要 (ReviewCompleteSummary — 条件渲染)
│   ├── 风险统计: 🔴高风险 N 项 | 🟡中风险 M 项 | 🟢低风险 K 项
│   └── "进入人工审批"引导按钮 → 跳转 P5
│
└── 底部操作栏
    ├── 审核生命周期状态标签（已创建→排队→执行→...）
    └── 辅助操作: 查看已解析条款 / 提前浏览文档
```

**数据来源**: 后端通过 SSE/WebSocket 推送 4 Agent 的实时状态事件。

### P5: 审阅工作台 — 并排视图（核心页面）

> **来源**: `flow_state_spec.md` §3.3 — 三级审批 + 8 操作 6 要素

**页面目的**: 人工审批的核心工作界面，左右并排展示文档原文与风险分析。

```
P5: 审阅工作台 (Workspace)
├── 顶部工具栏 (WorkspaceToolbar)
│   ├── 审阅任务标题
│   ├── 审批进度: "已完成 18/25 项审批"
│   ├── "暂存草稿"按钮
│   └── "提交审阅"按钮（灰色 → 所有高风险审批完成后可点击）
│
├── 左面板: 文档原文 (DocumentPanel)
│   ├── 文档工具栏（页面导航 / 搜索 / 缩放）
│   ├── 合同原文渲染区（支持 PDF/DOCX 渲染）
│   ├── 条款高亮覆盖层:
│   │   ├── 🔴 红色高亮 = 高风险条款（带序号标记）
│   │   ├── 🟡 黄色高亮 = 中风险条款
│   │   └── 🟢 绿色标记 = 低风险条款
│   ├── 点击高亮区域 → 右面板自动滚动到对应风险卡片
│   └── 划选文本 → 浮动工具条（手动补充标记入口）
│
├── 右面板: 风险审核面板 (RiskReviewPanel)
│   │
│   ├── 模式切换 Tab: [高风险审批 (N)] [中风险批审 (M)] [低风险抽样 (K)]
│   │
│   ├── Tab 1: 高风险审批（HighRiskTab） — 强制逐条
│   │   ├── 审批卡片 (ApprovalCard):
│   │   │   ├── ① 条款定位区: Clause 类型 + 原文引用 + "在文档中查看"按钮
│   │   │   ├── ② AI 判定区: 风险等级(🔴)+ 风险类别 + AI 置信度 XX%
│   │   │   ├── ③ Playbook 对比区: Playbook 标准条款 vs 实际条款 diff
│   │   │   ├── ④ 修改建议区: AI 建议修改措辞
│   │   │   ├── ⑤ 审批历史区: (如有) 历史相似条款的审阅决策
│   │   │   └── ⑥ 操作区:
│   │   │       ├── [✅ 同意 (Approve)] — 确认 AI 标记
│   │   │       ├── [✏️ 编辑 (Edit)] — 修改风险等级/类别/建议措辞
│   │   │       └── [❌ 驳回 (Reject)] — 移除标记 + 填写原因
│   │   ├── 审批进度计数: "第 3/8 项"
│   │   └── 强制约束: 全部高风险审批完成前，"提交"按钮灰色不可点击
│   │
│   ├── Tab 2: 中风险审批（MediumRiskTab） — 批量可选
│   │   ├── 批量操作条: "全部确认"按钮
│   │   ├── 中风险条款列表（每条可展开）
│   │   │   ├── 展开前: 条款类型 | 风险类别 | 标记状态
│   │   │   └── 展开后: 复用高风险审批卡片（同上 ①-⑥ 区）
│   │   └── 标记区分: "未审核-自动通过" vs "已审核-确认"
│   │
│   └── Tab 3: 低风险抽样（LowRiskTab） — 默认折叠
│       ├── 默认折叠列表: "AI 已自动通过 K 项低风险条款 [展开查看]"
│       ├── 抽样审计入口: "抽查 N 项 (本次抽取 11%)"
│       └── 发现问题 → 升级路径: 低→高 Mark 并强制审核
│
├── 手动补充标记入口 (ManualFlagToolbar)
│   ├── 触发方式: 左面板划选原文区域 → 浮动工具条
│   ├── 浮动工具条: [设置风险等级] [选择风险类别] [填写说明]
│   └── 提交后: 生成人工来源标记 → 直接计入高风险队列（需审批确认）
│
└── 审批完成确认对话框 (SubmitConfirmDialog)
    ├── 审阅摘要统计: 已确认 N / 已修正 M / 已驳回 K / 手动补充 J
    ├── [确认提交] — 触发后端报告生成
    └── [取消，继续审阅]
```

**数据来源**:

- 左面板: 后端提供文档渲染数据（PDF/DOCX → HTML/Canvas）+ 条款高亮位置数据
- 右面板: 后端提供 RiskFlag 列表 + PlaybookRule 对比数据 + AI 置信度 + 历史决策
- 操作: 前端发起 approve/edit/reject/submit，后端返回更新后的状态

```
      └─────┬─────┘      │         │
            │ 解析完成    │         │
            ▼            │         │
      ┌───────────┐      │         │
      │ P4 AI审核  │      │         │
      └─────┬─────┘      │         │
            │ 审核完成    │         │
            ▼            │         │
      ┌───────────┐      │         │
      │ P5 审阅工作台│◄────┼─────────┘ (继续审阅)
      └─────┬─────┘      │
            │ 提交        │
            ▼            │
      ┌───────────┐      │
      │ P6 报告预览 │◄────┼──────────┘ (查看报告)
      └───────────┘      │
                         │
          ┌──────────────┘
          │ 主流程: P1→P2→P3→P4→P5→P6
          │ 辅助路径: P1→P7→P5/P6 (恢复/查看)
```

**页面跳转触发条件与前置状态**：

| 跳转 | 触发 | 前置条件 |
|------|------|---------|
| P1 → P2 | 点击"新建审阅" | 用户已登录 |
| P2 → P3 | 点击"开始解析" | 文件上传完成 + 校验通过 + 配置完成 |
| P3 → P4 | 解析完成（自动） | 解析状态 = COMPLETED |
| P3 → P2 | 解析失败 → "重新上传" | 解析状态 = FAILED（不可恢复） |
| P3 → P3 | 解析失败 → "重试" | 解析状态 = FAILED（Checkpointer 断点续传） |
| P4 → P5 | 审核完成 → "进入人工审批" | AI 审核状态 = COMPLETED / PARTIAL_SUCCESS |
| P4 → P2 | 审核失败（解析残留）→ "重新上传" | AI 审核状态 = FAILED_PARSE_ERROR |
| P5 → P6 | 点击"确认提交" | 所有高风险审批完成 + 用户确认 |
| P5 → P5 | 点击"暂存草稿" | 任何时候 |
| P1 → P5/P6 | 点击历史/最近审阅 | 任务状态为 DRAFT（→P5）或 SUBMITTED（→P6） |

## 五、核心交互规范

> **来源**: `flow_state_spec.md` §三 + `business_model.md` §四 业务实体

### 5.1 分级告警交互

| 告警等级 | 视觉标识 | 审批方式 | 操作控件 | 是否可跳过 |
|---------|---------|---------|---------|:--------:|
| 🔴 高风险 | 红色背景 + 边框 | 逐条强制审批 | approve / edit / reject | **不可跳过** |
| 🟡 中风险 | 黄色背景 | 批量 + 选择性深入 | "全部确认" / 展开深入 | 可批量跳过（标记 auto-passed） |
| 🟢 低风险 | 绿色标记 | 自动通过 | "展开查看" + "抽样审计" | 默认跳过（有抽样） |

### 5.2 审批操作 6 要素规范

> **来源**: `flow_state_spec.md` §3.3 — 8 操作 6 要素

| 操作 | 触发条件 | 系统响应 | 用户可操作 | UI 要素 | 数据变更 | 下一状态 |
|------|---------|---------|-----------|--------|---------|---------|
| **approve** | 点击审批卡片的"同意" | 标记为 approved | 可撤销 | 绿色确认勾 | RiskFlag.status → CONFIRMED | 进入下一审批项 |
| **edit** | 点击审批卡片的"编辑" | 进入编辑模式 | 修改等级/类别/措辞 | 编辑表单覆盖卡片 | RiskFlag.status → AMENDED + 保存修改字段 | 进入下一审批项 |
| **reject** | 点击审批卡片的"驳回" | 弹出驳回原因对话框 | 填写驳回原因 + 确认 | 输入框 + 确认按钮 | RiskFlag.status → REJECTED + 驳回原因 | 该标记移除，进入下一项 |
| **batch_approve** | 点击中风险 Tab 的"全部确认" | 批量标记为 auto-passed | 可个别展开修改 | 确认按钮 + 进度提示 | 所有中风险 RiskFlag.status → UNREVIEWED_AUTO_PASSED | 中风险审批完成 |
| **spot_check** | 点击低风险 Tab 的"抽样审计" | 随机抽取 N 项 | 逐项审查 | 抽样审计详情面板 | 抽样项可能被升级 | 继续审批 / 升级 |
| **escalate** | 抽样审计中发现需升级项 | 弹出升级确认 | 确认升级 | 升级确认对话框 | RiskFlag.risk_level → HIGH | 该标记进入高风险审批队列 |
| **manual_add** | 左面板划选原文区域 | 弹出浮动工具条 | 设置等级+类别+说明 | 浮动工具条 → 标记表单 | 创建人工来源 RiskFlag | 标记进入高风险队列 |
| **final_submit** | 所有高风险项审批完成 + 点击"提交" | 触发报告生成 | 确认提交 or 取消 | 审阅摘要 + 确认对话框 | Document.status → SUBMITTED → 生成 ReviewReport | P5 → P6 |

### 5.3 并排视图同步交互

> **来源**: `flow_state_spec.md` §3.3 + `business_model.md` §3.2 场景 2

```
左面板 (文档原文)                        右面板 (风险审核)
─────────────────                      ─────────────────
                                              │
  条款区域 #5 (🟡中风险) ◄──────── 双向同步 ──────┼── 点击风险卡片 #3 → 左面板自动滚动到条款区域 #5 并高亮
                                              │
  用户划选区域 ────────────── 单向触发 ──────────▶│── 浮动工具条出现 → 手动补充标记
```

**同步规则**:
- 点击右面板风险卡片 → 左面板自动滚动定位 + 高亮（`scrollIntoView` 行为，平滑滚动）
- 左面板手动划选 → 右面板不滚动（单向触发），浮动工具条覆盖在左面板划选区域上方
- 键盘快捷键: `J` 下一风险项, `K` 上一风险项, `Enter` 确认当前, `Esc` 返回

### 5.4 不可跳过的 4 层约束

> **来源**: `flow_state_spec.md` §3.3 — 高风险不可跳过

| 层级 | 约束方式 | 说明 |
|:--:|---------|------|
| L1 | 工作流 `interrupt()` | 后端 LangGraph 节点在人类响应前不继续，永久等待 |
| L2 | API 409 Conflict | 前端尝试提交时，后端校验高风险审批完整性，不完整则返回 409 |
| L3 | UI 置灰 | "提交审阅"按钮在所有高风险项审批完成前处于 disabled 状态 |
| L4 | 并发锁 | 同一审批项不允许同时被两个会话修改 |

### 5.5 异常交互规范

> **来源**: `flow_state_spec.md` §3.1 异常路径 + §3.2 失败/中断

| 异常场景 | 阶段 | 系统响应 | 用户操作 |
|---------|:--:|---------|---------|
| 上传格式不支持 | P2 | 即时错误提示 + 支持的格式列表 | 重新选择文件 |
| 文件加密 | P2 | 即时错误提示 | 解除保护后重试 |
| 文件损坏 | P2 | 服务端检测后错误提示 | 重新导出 PDF |
| 网络中断 (上传中) | P2 | 断点续传，恢复后继续 | 等待恢复 or 取消 |
| 网络中断 (审核中) | P4 | Checkpointer 保存状态 | 恢复后"从中断处继续" |
| 解析失败 (可恢复) | P3 | 失败原因 + 已完成进度 | "重试"（断点续传） |
| 解析失败 (不可恢复) | P3 | 完整错误信息 | "重新上传" |
| AI 服务不可用 | P4 | 错误提示 + 状态保持 | "重试" or "人工接管" |
| 审核超时 | P4 | 已完成部分保留 | 查看已完成条款 or 重试 |
| 并发上传限制 | P2 | 排队提示 | 等待 or 取消其他任务 |
| 重复文件 | P2 | 警告提示 | 确认重复上传 or 取消 |
